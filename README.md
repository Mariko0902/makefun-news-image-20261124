**The World in One Day** — a flat editorial newspaper front page summing up the world news of Tuesday, November 24, 2026, in a single 1024×1024 image: Ukraine sinks a Russian warship off Libya, Riyadh's tallest tower hit again, the Zaporizhzhia strike, Jensen Huang back at Nvidia, COP31 talks collapse, and more from that day. The artwork is authored as SVG (`frontpage.svg`) and rendered to PNG with `@resvg/resvg-js` (`render.mjs`).

## Run it

```sh
node main.ts
```

This copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output`). Run `node render.mjs` first if you want to rebuild the PNG from the SVG source.
