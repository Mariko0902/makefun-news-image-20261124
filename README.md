# The World in One Day

A flat editorial newspaper front page summarizing the world news of Tuesday, November 24, 2026. The artwork is authored as SVG and rendered to PNG with `@resvg/resvg-js`.

Run `node main.ts` to copy `entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output`), or run `node render.mjs` to rebuild the PNG from `frontpage.svg`.
